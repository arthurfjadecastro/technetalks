## Agent skills

Configuração canônica de tracker, triage labels e domain docs na seção **Agent skills** de AGENTS.md e em `docs/agents/`. Leia essa seção antes das skills de engenharia.
O pacote Matt Pocock pode estar disponível como plugin pessoal. Se ausente, leia a skill correspondente em `.agents/skills/<nome>/SKILL.md` com todos os recursos nela referenciados. O adaptador `/project-continuity-claude` aponta para a skill compartilhada. Não configure um segundo tracker.
